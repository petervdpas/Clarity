# Waves

Generated by Clarity from the project Waves: Go with the web renderer. Do not edit these files; change the project in Clarity and generate it again.

## What you need

- Go, from https://go.dev/dl
- on Linux, the WebKitGTK development files and pkg-config (Debian and Ubuntu: libwebkit2gtk-4.1-dev; see https://tauri.app/start/prerequisites/)

Clarity looks for these itself (`clarity tools`, and Build tools on the Project tab); this list is for building the project without it.

Clarity's runtime comes as the Go module github.com/petervdpas/Clarity/runtimes/go (v0.23.0), with a package for each server database the project uses, which the first build fetches. To build on the runtime in Clarity's repository instead, while working on it, make a workspace next to this module:

    go work init .
    go work edit -replace github.com/petervdpas/Clarity/runtimes/go=<Clarity>/runtimes/go

Clarity keeps go.work when it writes the module again; remove it to build on the published module.

## Build and run

In this folder, build the program with

    go build -tags production -trimpath -ldflags="-s -w" -o bin/waves .

which writes `bin/waves.exe`. To try it while you work, build a debug program and start it with

    go run .

## Data

- `main`: the SQLite file `E:\Projects\Clarity\examples\waves\data\waves.db`, migrated by the program when it starts; a relative path is taken from the folder the program starts in.
