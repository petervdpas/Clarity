# Clarity.AppMcp

Clarity.AppMcp for C#: the native library of the MCP service of an application generated by
[Clarity](https://github.com/petervdpas/Clarity), which offers the application's commands for agents
(a `command` with an `agent` line) to AI agents, exactly as every other stack Clarity generates does, on
Linux, Windows and macOS.

Clarity's generator adds this package to a command-line program with a command for agents; `<program> mcp`
then serves those commands over standard input and output:

```csharp
return Clarity.AppMcp.AgentService.RunProgram(Program(), new Agents(Tools, "Shop", "shop", "1.0"), args, Run);
```

While the application is closed nobody is there to grant a change: the person's settings
`agentReadsWhileClosed` and `agentChangesWhileClosed` allow reads and changes, else they are refused.
