# Clarity.Audio

Clarity.Audio for C#: the native library that plays the songs (mp3, flac, wav and ogg) of an
application generated by [Clarity](https://github.com/petervdpas/Clarity), with pause, seek,
the position and the length, on Linux, Windows and macOS.

Clarity's generator adds this package to a program whose sound parts play songs, and the
program hands it to Clarity.UI once, before its first window:

```csharp
Clarity.Audio.ClarityAudio.Use();
```
