# Clarity.Auth

Clarity.Auth for C#: the native library of the sign-in of an application generated by
[Clarity](https://github.com/petervdpas/Clarity): the strategies (a password, the computer's account,
a token), hashes, failed tries and sessions, exactly as every other stack Clarity generates does, on
Linux, Windows and macOS.

Clarity's generator adds this package to a program whose project signs people in
(`signin Member on desktop web` in the project file) and names its people after the databases open:

```csharp
db.AddSignin(new Clarity.Auth.SigninSource("members", "SignIn")
{
    Targets = ["desktop", "web"],
    Strategies = [new("password", ["email", "password_hash"]), new("account", ["login"])],
});
```

The database handle then signs people in (`db.Signin`, `db.SigninFirst`, `db.SigninCli`, `db.Signout`)
and code reads `db.Me<Member>()`. `Signins.Hashed(method, text, minimum)` is what a hashed field
stores, `Signins.NewToken()` and `Signins.NewRecoveryCodes(count)` make secrets. Every operation of
the native library goes through one call, its arguments and result as JSON:

```csharp
var found = Clarity.Auth.AuthCalls.Call("find", "{\"strategy\":\"password\",\"inputs\":{\"name\":\"ann\",\"password\":\"...\"}}");
```
