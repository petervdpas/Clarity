# Clarity.Formats

Clarity.Formats for C#: the native library of the data formats of an application generated by
[Clarity](https://github.com/petervdpas/Clarity) (JSON first), read and written exactly as every other
stack Clarity generates does, on Linux, Windows and macOS.

Clarity's generator adds this package to a program whose code reads or writes a format:

```csharp
var orders = Clarity.Formats.FormatFunctions.Read<List<Order>>("json", reply.Text, "{\"at\":\"data\"}", kind);
var body = Clarity.Formats.FormatFunctions.Write("json", order, "", kind);
```
