# Clarity.Image

Clarity.Image for C#: the native library of the picture functions of an application generated by
[Clarity](https://github.com/petervdpas/Clarity) (resize, crop, rotate, flip, blend, adjust and a
picture's size), giving the same pixels as every other stack Clarity generates, on Linux, Windows
and macOS.

Clarity's generator adds this package to a program whose code calls a picture function:

```csharp
var small = Clarity.Image.PictureFunctions.Resize(cover, 200, 300);
```
