# Clarity.Pdf

Clarity.Pdf for C#: the native library that makes the PDFs of an application generated by
[Clarity](https://github.com/petervdpas/Clarity). A Markdown text is laid out by Typst into pages
in a stylesheet's look (a subset of CSS over Clarity's own sheet), optionally reading the app's
theme, and the same text gives the same file on every stack Clarity generates, on Linux, Windows
and macOS. The fonts are carried in the library, so no internet is needed.

Clarity's generator adds this package to a program whose code makes a PDF (`pdf of`):

```csharp
byte[] file = Clarity.Pdf.PdfFunctions.Of("# Invoice\n\nThank you.", "h1 { color: #1f5fbf }", "");
```
