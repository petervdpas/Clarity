# Clarity.Ui

Clarity.UI for C#: Clarity's own UI framework (DESIGN 7.9). It draws the windows of applications generated by [Clarity](https://github.com/petervdpas/Clarity) itself, with Skia: the grid, Clarity's themes, text, and what the person does with the pointer and keys. Each stack has its version (Rust, Go, C, C++ and C#), alike in what they draw and reading the same window markup (`.cxaml`).

The windows' view models are the runtime's (`Clarity.Runtime`). Clarity.Ui draws them on the desktop through `Clarity.Ui.Desktop` and in a browser page through `Clarity.Ui.Browser`.
