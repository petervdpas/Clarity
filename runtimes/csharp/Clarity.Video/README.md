# Clarity.Video

Clarity.Video for C#: the native library that plays the videos of an application generated by
[Clarity](https://github.com/petervdpas/Clarity), with the system's own decoder (Media Foundation,
AVFoundation, GStreamer) or Cisco's openh264, which the package carries for each system so videos
play offline.

Clarity's generator adds this package, with Clarity.Audio for the sound, to a program with video
parts, and the program hands it to Clarity.UI once, before its first window:

```csharp
Clarity.Video.ClarityVideo.Use();
```

An application that carries openh264 makes its maker the holder of the H.264 licence (Via LA).
