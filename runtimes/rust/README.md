# clarity-runtime

The runtime of Rust applications generated by [Clarity](https://github.com/petervdpas/Clarity), a designer and language for desktop applications that generates real code for several stacks.

A generated application depends on this crate for:

- **Records and storage:** saving, finding and deleting records, with data events around a save or delete, in one transaction.
- **Queries:** conditions and ordering, also through references, as SQL for each database.
- **Migrations:** the steps Clarity writes, applied once each when the application starts.
- **Pictures and files:** pictures kept in the database or in a file store, and the files of a store.
- **The binding to the screen:** the state a window sends and the reply its handlers give.

## Databases

SQLite is on by default. Each server database is a feature, which a generated application turns on only for the databases its data sources use:

| Feature | Database |
|---|---|
| `sqlite` | SQLite (bundled) |
| `postgres` | PostgreSQL |
| `mysql` | MySQL |
| `mssql` | SQL Server |

```toml
clarity-runtime = { version = "0.1.0", default-features = false, features = ["sqlite", "postgres"] }
```

## Working on the runtime

A generated project builds on the runtime in Clarity's repository instead of this crate with a `.cargo/config.toml` in the project:

```toml
[patch.crates-io]
clarity-runtime = { path = "<Clarity>/runtimes/rust" }
```
